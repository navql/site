Beyond the query

Built for the work after SELECT.

See what the server is doing, stop what is stuck, find what is slow and keep a copy, without leaving NavQL for another tool.

pg_cancel_backend · KILL QUERY

Sessions, locks and cancel

The Activity tab lists every session on the server with its query, state and wait, including who blocks whom. Cancel a query or end a session from the same screen.

pg_stat_statements · performance_schema

Top queries and health

The statements that took the most time, from the server's own statistics. Health checks point at unused indexes, full scans and dead rows, with a suggested fix that never runs on its own.

pg_dump · mysqldump · mongodump

Backups in one click

The official dump tool runs in the background, streams straight to a file, works through the SSH tunnel and shows progress. Back up the whole database or only the tables you pick. SQLite uses its own online backup.

ALTER TABLE

Edit the structure

Change columns in place in the Structure view. NavQL shows the ALTER TABLE it will run and applies it only when you confirm.

References · Referenced by

Related rows, as a tree

Open a row and see everything linked to it by foreign keys, in both directions. Each row opens its own relationships, as many levels deep as you need.

JOIN · GROUP BY · HAVING

Visual query builder

Joins along foreign keys or with your own ON, filters, aggregates, HAVING and calculated columns, with the SQL written live as you click.

READ ONLY transaction

Read only that really is

Read-only connections accept only reading statements and, on PostgreSQL and MySQL, run them inside a READ ONLY transaction, so a CTE with DELETE is refused too.

TRUNCATE … CASCADE

Truncate cascade

Empty a table and every table that references it, directly or not, after seeing the list. On MySQL and SQLite, which have no cascade, NavQL empties them one by one.

CockroachDB · TimescaleDB · TiDB · Valkey · Dragonfly

Compatible servers by name

Detected and shown by name, with the differences handled: CANCEL QUERIES on CockroachDB, a rolled-back transaction for read only on TiDB, internal schemas kept out of autocomplete.

Questions

Good to know.

Is NavQL free?

Yes. NavQL is free of charge for personal and commercial work, on any number of your own computers. It is not open source.

Which databases does NavQL support?

PostgreSQL, MySQL, MariaDB, SQL Server, SQLite, MongoDB and Redis. It also connects to compatible servers such as CockroachDB, TimescaleDB, Supabase, Neon, TiDB, Valkey and Dragonfly.

Does NavQL run on Mac, Windows and Linux?

NavQL runs on macOS (Apple Silicon), on Windows 10 and 11, and on Linux (x64), as an AppImage that updates itself or a .deb package for Debian and Ubuntu.

Where are my connections and passwords stored?

Only on your computer. Passwords and SSH keys are encrypted with a key protected by your operating system, and NavQL connects directly from your computer to your databases. Nothing about your connections, queries or data is sent to us.

Can I reach a database on a private network?

Yes. Every connection can use a built-in SSH tunnel and SSL, so you can reach databases that are not open to the internet.

Can NavQL show active sessions and cancel a query?

Yes. The Activity tab lists every session on the server with its query, state and wait, including who blocks whom, and lets you cancel the query or end the session. The same tab shows top queries from the server's own statistics and health checks with suggested fixes. It works on every supported database except SQLite.

How does the AI assistant work?

It is optional and uses your own Anthropic API key. When you ask it to write or explain SQL, it sends the structure of your database (table and column names, types and keys) and the text of the editor, never the data in your tables.

Can I install NavQL from the terminal?

Yes. On macOS run brew install --cask navql/tap/navql; on Windows, in PowerShell, irm https://navql.com/install.ps1 | iex; on Linux, curl -fsSL https://navql.com/install.sh | sh. Each installs the latest version for your user, without administrator rights.

How do I update NavQL?

You do not have to. NavQL checks for new versions on its own, downloads them in the background and installs them when you restart the app.

  • Windows: & ([scriptblock]::Create((irm https://navql.com/install.ps1))) -Uninstall
