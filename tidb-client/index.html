What NavQL does with TiDB

Built for the way you work with TiDB.

Everything below works on TiDB today. TiDB speaks the MySQL protocol, so it uses NavQL's MySQL support, with the differences handled for you.

Top queries from statements_summary

Total time, calls, mean, max, rows and rows examined, with a warning when a statement reads far more rows than it returns. Open one in the editor as a real execution with its values.

Read only without READ ONLY

TiDB has no READ ONLY transaction, so on a read-only connection NavQL runs each statement in a transaction that is always rolled back.

Detected, with its settings

The status bar shows the real server (TiDB 7.5.1); tidb:// and *.tidbcloud.com URLs are recognized; Settings reads VARIABLES_INFO.

Edit rows, then commit once

Change cells, insert, duplicate and delete rows in the grid. Every change stays pending (yellow, green, red) until you press ⌘S; Preview shows the SQL first and the whole batch commits in one transaction.

Related rows, as a tree

Open a row and see everything linked to it by foreign keys: the rows it points to and, for each table that points back, how many rows and the first ones. Each row opens its own relationships, as many levels deep as you like.

Visual query builder

Pick a table, add the tables linked to it by foreign keys (or join any table with your own ON), filters, aggregates, HAVING and calculated columns. The SQL is written live, and you can save the builder or open the SQL in an editor tab.

Also included

The details that save time.

  • Sessions with KILL QUERY and KILL
  • Structure, DDL and diagram from the foreign keys
  • SQL editor with autocomplete and several result tabs
  • Export to CSV, JSON or SQL; import CSV
  • SSH tunnel and SSL

Not yet

What NavQL does not do on TiDB today.

So you know before you download.

  • Backups (use TiDB's BR or Dumpling)

Questions

Good to know.

Does NavQL work with TiDB Cloud Serverless?

Yes. Paste the connection string; NavQL recognizes *.tidbcloud.com and connects with SSL.

Why are TiDB backups not available?

NavQL's backups use mysqldump, which is not the recommended tool for TiDB. Use BR or Dumpling.
