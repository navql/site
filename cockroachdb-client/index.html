What NavQL does with CockroachDB

Built for the way you work with CockroachDB.

Everything below works on CockroachDB today. CockroachDB speaks the PostgreSQL protocol, so it uses NavQL's PostgreSQL support, with the differences handled for you.

Detected, not assumed

The status bar shows the real server, such as CockroachDB 26.4.0. URLs with cockroachdb:// or a *.cockroachlabs.cloud host are recognized on import.

Cancel the CockroachDB way

There is no pg_cancel_backend on CockroachDB, so NavQL cancels with CANCEL QUERIES, from the editor and from the Activity tab.

Cluster settings

The Settings view reads SHOW CLUSTER SETTINGS, separating changed and important ones from all.

Clean autocomplete

Internal schemas such as crdb_internal stay out of autocomplete, so suggestions are your tables.

Edit rows, then commit once

Change cells, insert, duplicate and delete rows in the grid. Every change stays pending (yellow, green, red) until you press ⌘S; Preview shows the SQL first and the whole batch commits in one transaction.

Related rows, as a tree

Open a row and see everything linked to it by foreign keys: the rows it points to and, for each table that points back, how many rows and the first ones. Each row opens its own relationships, as many levels deep as you like.

Also included

The details that save time.

  • Structure, DDL and database diagram from the foreign keys
  • Visual query builder with foreign-key joins and aggregates
  • Read-only connections accept only reading statements
  • SSH tunnel and SSL, with colors and tags per connection
  • Export to CSV, JSON or SQL

Not yet

What NavQL does not do on CockroachDB today.

So you know before you download.

  • Backups (pg_dump does not support CockroachDB; use CockroachDB's BACKUP)

Questions

Good to know.

Does NavQL support CockroachDB Cloud?

Yes. Paste the connection string; NavQL recognizes *.cockroachlabs.cloud and uses SSL.

Why does NavQL not back up CockroachDB?

Its backups use pg_dump, which CockroachDB does not support. CockroachDB has its own BACKUP statement.

Which PostgreSQL features work on CockroachDB?

The grid, editor, structure, diagram, related rows, query builder, sessions and settings all work. Where CockroachDB differs, such as cancelling queries, NavQL uses its own commands.
