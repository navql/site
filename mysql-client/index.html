What NavQL does with MySQL

Built for the way you work with MySQL.

Everything below works on MySQL today.

Edit rows, then commit once

Change cells, insert, duplicate and delete rows in the grid. Every change stays pending (yellow, green, red) until you press ⌘S; Preview shows the SQL first and the whole batch commits in one transaction.

SQL editor that knows your schema

Autocomplete for tables and columns, ⌘↵ runs the statement under the cursor, ⌘I formats, and several result sets open in tabs. Saved queries and history are kept per connection.

Top queries, with rows examined

From performance_schema: total time, calls, mean, max, rows and rows examined, shown in orange when a statement reads hundreds of rows for each one it returns, a sign of a missing index.

Backups with mysqldump

One click runs mysqldump --single-transaction --quick in the background and writes a .sql.gz, through the SSH tunnel if the connection uses one.

Related rows, as a tree

Open a row and see everything linked to it by foreign keys: the rows it points to and, for each table that points back, how many rows and the first ones. Each row opens its own relationships, as many levels deep as you like.

Read only that really is

Mark a connection Read only and NavQL accepts only reading statements, then runs them inside a READ ONLY transaction on MySQL, so a CTE with DELETE or a function that writes is refused too.

Also included

The details that save time.

  • Sessions with KILL QUERY to cancel a statement and KILL to end a connection
  • Health finds unused and duplicate indexes, tables read by full scans, tables without a primary key and free space to reclaim with OPTIMIZE TABLE
  • Settings from variables_info, with defaults; suggested changes come as SET PERSIST
  • On MySQL 8, open a top query in the editor as a real execution with its values
  • Truncate cascade: MySQL has no cascade, so NavQL empties each referencing table with foreign key checks off for that connection only
  • DDL from SHOW CREATE; edit columns in place, applied as one ALTER TABLE
  • Visual query builder with foreign-key joins, aggregates and HAVING
  • Database diagram, export to CSV, JSON and SQL, CSV import

Questions

Good to know.

Is NavQL a free alternative to MySQL Workbench?

NavQL is free and covers daily work with MySQL: browsing, editing, queries, structure, monitoring and backups. It does not do data modeling or server provisioning like MySQL Workbench.

Can I connect to MySQL over SSH?

Yes. Every connection can use a built-in SSH tunnel with a password or private key, plus SSL/TLS.

Why are top queries empty?

They come from performance_schema. When statement collection is off, the Activity tab explains how to turn it on.

Does NavQL support TiDB and MariaDB?

Yes, both have their own page. MariaDB uses the same features as MySQL; TiDB adds statements_summary for top queries.
