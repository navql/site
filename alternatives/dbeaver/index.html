Choose DBeaver if

DBeaver may be the better pick when…

  • You need a database NavQL does not support, such as Oracle, ClickHouse or DuckDB
  • You want an open-source tool
  • You need data transfer, comparison or other advanced tasks

Choose NavQL if

NavQL is the better pick when…

  • You want a fast, focused app with less to configure
  • You want MongoDB and Redis next to SQL in a free app
  • You want top queries, health checks and server settings in one view

Only in NavQL

What NavQL brings to the table.

Related rows, as a tree

Open a row and see everything linked to it by foreign keys: the rows it points to and, for each table that points back, how many rows and the first ones. Each row opens its own relationships, as many levels deep as you like.

Activity tab

Sessions with their queries and locks, who blocks whom, cancel or end a session, top queries from the server's own statistics, health checks with suggested fixes and server settings, on PostgreSQL, MySQL, MariaDB, SQL Server, MongoDB, Redis and compatible servers.

Backups in one click

pg_dump, mysqldump and mongodump run in the background, stream straight to a file and work through the SSH tunnel. SQLite uses its own online backup.

Visual query builder

Pick a table, add the tables linked to it by foreign keys (or join any table with your own ON), filters, aggregates, HAVING and calculated columns. The SQL is written live, and you can save the builder or open the SQL in an editor tab.

Read only that really is

Read-only connections accept only reading statements. On PostgreSQL and MySQL they also run inside a READ ONLY transaction, so a CTE with DELETE is refused.

Compatible servers by name

CockroachDB, TimescaleDB, Supabase, Neon, TiDB, Valkey and Dragonfly are detected, shown by name and handled where they differ.

Questions

Good to know.

Does NavQL support as many databases as DBeaver?

No. NavQL supports PostgreSQL, MySQL, MariaDB, SQL Server, SQLite, MongoDB and Redis, plus compatible servers. DBeaver supports many more.

Is NavQL open source like DBeaver Community?

No. NavQL is free of charge but not open source.

Is NavQL really free?

Yes. NavQL is free of charge for personal and commercial work, on any number of your own computers. It is not open source.

Where does NavQL keep my passwords?

Only on your computer, encrypted with a key protected by your operating system. NavQL connects directly from your computer to your databases.
