Choose DB Pro if

DB Pro may be the better pick when…

  • You use ClickHouse, DynamoDB or Turso
  • You want dashboards and workflows built from queries
  • You want to choose between several AI providers or a local model
  • You want a web workspace for a team

Choose NavQL if

NavQL is the better pick when…

  • You want to see sessions and locks and cancel a query today
  • You want top queries and health checks from the server's own statistics
  • You want one-click backups with pg_dump, mysqldump or mongodump
  • You want real read-only connections and truncate cascade
  • You use CockroachDB, TimescaleDB, TiDB, Valkey or Dragonfly
  • You want more than 2 connections and 3 tabs without paying

Where NavQL goes deeper

Built for the work after SELECT.

DB Pro is strong at dashboards, workflows and AI. NavQL is strong at managing the database itself: what the server is doing, what to stop, what to fix and how to keep a copy. All of this works in NavQL today.

pg_cancel_backend · KILL QUERY

Sessions, locks and cancel

The Activity tab lists every session on the server with its query, state and wait, including who blocks whom. Cancel a query or end a session from the same screen.

pg_stat_statements · performance_schema

Top queries and health

The statements that took the most time, from the server's own statistics. Health checks point at unused indexes, full scans and dead rows, with a suggested fix that never runs on its own.

pg_dump · mysqldump · mongodump

Backups in one click

The official dump tool runs in the background, streams straight to a file, works through the SSH tunnel and shows progress. SQLite uses its own online backup.

ALTER TABLE

Edit the structure

Change columns in place in the Structure view. NavQL shows the ALTER TABLE it will run and applies it only when you confirm.

References · Referenced by

Related rows, as a tree

Open a row and see everything linked to it by foreign keys, in both directions. Each row opens its own relationships, as many levels deep as you need.

JOIN · GROUP BY · HAVING

Visual query builder

Joins along foreign keys or with your own ON, filters, aggregates, HAVING and calculated columns, with the SQL written live as you click.

READ ONLY transaction

Read only that really is

Read-only connections accept only reading statements and, on PostgreSQL and MySQL, run them inside a READ ONLY transaction, so a CTE with DELETE is refused too.

TRUNCATE … CASCADE

Truncate cascade

Empty a table and every table that references it, directly or not, after seeing the list. On MySQL and SQLite, which have no cascade, NavQL empties them one by one.

CockroachDB · TimescaleDB · TiDB · Valkey · Dragonfly

Compatible servers by name

Detected and shown by name, with the differences handled: CANCEL QUERIES on CockroachDB, a rolled-back transaction for read only on TiDB, internal schemas kept out of autocomplete.

Questions

Good to know.

Is DB Pro free?

It has a free plan with limits (2 connections, 3 open tabs, 5 saved queries, 1 device) and paid plans. NavQL is free without those limits.

Can NavQL cancel a running query?

Yes. From the editor, or from the Activity tab, where every session on the server is listed with its query. You can also end a session. On DB Pro, cancelling a running query is on its roadmap.

Can NavQL back up a database?

Yes, in one click: PostgreSQL with pg_dump, MySQL and MariaDB with mysqldump, MongoDB with mongodump and SQLite with its online backup. Restore with the database's own tool. SQL Server, Redis, CockroachDB and TiDB backups are not available yet.

Is NavQL really free?

Yes. NavQL is free of charge for personal and commercial work, on any number of your own computers. It is not open source.

Where does NavQL keep my passwords?

Only on your computer, encrypted with a key protected by your operating system. NavQL connects directly from your computer to your databases.
