What NavQL does with Neon

Built for the way you work with Neon.

Everything below works on Neon today. Neon speaks the PostgreSQL protocol, so it uses NavQL's PostgreSQL support, with the differences handled for you.

Paste the connection string

NavQL recognizes the *.neon.tech host when you import the URL, and shows Neon with its own name and icon.

One connection per branch

Save each Neon branch as its own connection, with a color and tag, and group them in a project so production never looks like a preview branch.

Edit rows, then commit once

Change cells, insert, duplicate and delete rows in the grid. Every change stays pending (yellow, green, red) until you press ⌘S; Preview shows the SQL first and the whole batch commits in one transaction.

Related rows, as a tree

Open a row and see everything linked to it by foreign keys: the rows it points to and, for each table that points back, how many rows and the first ones. Each row opens its own relationships, as many levels deep as you like.

Activity: sessions, top queries, health

Every session on the Neon server with its query, state and wait, including who blocks whom. Cancel a query or end a session (pg_cancel_backend, pg_terminate_backend). Top queries come from pg_stat_statements.

Backups with pg_dump

Back up a whole database in one click with pg_dump --format=custom. It runs in the background, streams straight to a file, works through the SSH tunnel and shows progress. Restore with pg_restore.

Also included

The details that save time.

  • Structure editing with ALTER TABLE, diagram and visual query builder
  • Read-only connections with a READ ONLY transaction
  • SQL editor with autocomplete, saved queries and history
  • Export to CSV, JSON or SQL; import CSV as pending rows
  • SSL for hosted databases

Not yet

What NavQL does not do on Neon today.

So you know before you download.

  • Neon-specific screens such as creating branches: use the Neon console for that

Questions

Good to know.

How do I connect NavQL to Neon?

Copy the connection string from the Neon console and paste it into "Import from URL" in NavQL.

Can I back up a Neon branch?

Yes, with pg_dump from NavQL. Use a pg_dump at least as new as the branch's Postgres version.
