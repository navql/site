What NavQL does with SQLite

Built for the way you work with SQLite.

Everything below works on SQLite today.

Edit rows, then commit once

Change cells, insert, duplicate and delete rows in the grid. Every change stays pending (yellow, green, red) until you press ⌘S; Preview shows the SQL first and the whole batch commits in one transaction.

Edit the structure

Columns, indexes, foreign keys and the DDL of every table. Edit columns in place and NavQL applies the change as ALTER TABLE, after showing you the statement.

Database diagram

One click draws every table and the foreign keys between them, laid out automatically. Click a table to highlight what it touches; export the diagram as PNG or SVG.

Related rows, as a tree

Open a row and see everything linked to it by foreign keys: the rows it points to and, for each table that points back, how many rows and the first ones. Each row opens its own relationships, as many levels deep as you like.

Visual query builder

Pick a table, add the tables linked to it by foreign keys (or join any table with your own ON), filters, aggregates, HAVING and calculated columns. The SQL is written live, and you can save the builder or open the SQL in an editor tab.

Online backup

Back up a SQLite database with SQLite's own online backup, safe while the file is in use. The result is a plain .sqlite file.

Also included

The details that save time.

  • DDL read from sqlite_master
  • Read-only connections use SQLite's own readonly check on every statement
  • Truncate cascade runs a DELETE on each referencing table, in one transaction
  • SQL editor with autocomplete, formatting and several result tabs
  • Export to CSV, JSON or SQL, and import a CSV as pending rows

Not yet

What NavQL does not do on SQLite today.

So you know before you download.

  • The Activity tab (SQLite has no server to watch)
  • Creating a new database file from the app

Questions

Good to know.

Is NavQL a free alternative to DB Browser for SQLite?

Yes, NavQL is free. It adds a diagram, related rows, a visual query builder and the same app for your server databases.

Can I open a SQLite file from an iOS or Android app?

Yes, if you copy the file to your computer. NavQL opens any SQLite 3 database file.

Does editing lock my SQLite file?

Changes are written only when you commit, in one transaction, so the file is locked just for that moment.
