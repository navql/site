What NavQL does with Supabase

Built for the way you work with Supabase.

Everything below works on Supabase today. Supabase speaks the PostgreSQL protocol, so it uses NavQL's PostgreSQL support, with the differences handled for you.

Paste the connection string

Import the URL from your project's settings and NavQL recognizes the *.supabase.co host, shows Supabase with its own name and icon, and fills in the form.

Top queries on Supabase

Supabase installs pg_stat_statements in the extensions schema; NavQL finds it there and lists top queries by total time, calls, mean and rows.

Edit rows, then commit once

Change cells, insert, duplicate and delete rows in the grid. Every change stays pending (yellow, green, red) until you press ⌘S; Preview shows the SQL first and the whole batch commits in one transaction.

Related rows, as a tree

Open a row and see everything linked to it by foreign keys: the rows it points to and, for each table that points back, how many rows and the first ones. Each row opens its own relationships, as many levels deep as you like.

Backups with pg_dump

Back up a whole database in one click with pg_dump --format=custom. It runs in the background, streams straight to a file, works through the SSH tunnel and shows progress. Restore with pg_restore.

Read only that really is

Mark a connection Read only and NavQL accepts only reading statements, then runs them inside a READ ONLY transaction on Supabase's PostgreSQL, so a CTE with DELETE or a function that writes is refused too.

Questions

Good to know.

How do I connect NavQL to Supabase?

Copy the connection string of your project's database (direct or pooler) and paste it into NavQL's "Import from URL". NavQL recognizes Supabase from the host.

Is it safe to browse my production Supabase database?

Mark the connection Read only: NavQL then accepts only reading statements and runs them in a READ ONLY transaction.

Can I back up a Supabase database?

Yes. NavQL runs pg_dump against it; you need a pg_dump at least as new as the Postgres version of your project.
