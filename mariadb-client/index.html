What NavQL does with MariaDB

Built for the way you work with MariaDB.

Everything below works on MariaDB today.

Edit rows, then commit once

Change cells, insert, duplicate and delete rows in the grid. Every change stays pending (yellow, green, red) until you press ⌘S; Preview shows the SQL first and the whole batch commits in one transaction.

Edit the structure

Columns, indexes, foreign keys and the DDL of every table. Edit columns in place and NavQL applies the change as ALTER TABLE, after showing you the statement.

Activity and health

Sessions with their queries and locks, KILL QUERY and KILL, top queries with rows examined, and a health check for unused indexes, full scans and space to reclaim with OPTIMIZE TABLE.

Backups with mysqldump

One click runs mysqldump --single-transaction --quick in the background and gives you a compressed .sql.gz to download.

Related rows, as a tree

Open a row and see everything linked to it by foreign keys: the rows it points to and, for each table that points back, how many rows and the first ones. Each row opens its own relationships, as many levels deep as you like.

Visual query builder

Pick a table, add the tables linked to it by foreign keys (or join any table with your own ON), filters, aggregates, HAVING and calculated columns. The SQL is written live, and you can save the builder or open the SQL in an editor tab.

Also included

The details that save time.

  • Settings from SYSTEM_VARIABLES, with defaults and whether a change needs a restart
  • Read-only connections run statements inside a READ ONLY transaction
  • SQL editor with autocomplete, formatting and several result tabs
  • Follow a foreign key from a cell to the referenced row
  • Truncate cascade across the tables that reference the one you empty
  • Database diagram, CSV/JSON/SQL export and CSV import
  • SSH tunnel, SSL, Safe mode (confirms writes with a SQL preview)

Not yet

What NavQL does not do on MariaDB today.

So you know before you download.

  • Restoring a backup from inside the app
  • Creating a table from a form

Questions

Good to know.

Is MariaDB handled differently from MySQL?

NavQL knows when it is talking to MariaDB: ALTER TABLE statements and server settings use MariaDB's own syntax and tables. Everything else works the same as with MySQL.

Is NavQL free for work?

Yes, free for personal and commercial work, on any number of your own computers. It is not open source.

Can I back up a large MariaDB database?

Yes. The dump is written straight to a file, never held in memory, so the size of the database does not matter. mysqldump must be installed on your computer.
