What NavQL does with SQL Server

Built for the way you work with SQL Server.

Everything below works on SQL Server today.

Edit rows, then commit once

Change cells, insert, duplicate and delete rows in the grid. Every change stays pending (yellow, green, red) until you press ⌘S; Preview shows the SQL first and the whole batch commits in one transaction.

Related rows, as a tree

Open a row and see everything linked to it by foreign keys: the rows it points to and, for each table that points back, how many rows and the first ones. Each row opens its own relationships, as many levels deep as you like.

Sessions and top queries

Every session with its query and what it waits on, including blocking, and end session. Top queries come from the plan cache: total time, calls, mean, max and rows.

Health for SQL Server

Lists the indexes the optimizer asked for, heap tables, unused and duplicate indexes and tables without a primary key, each with the suggested CREATE INDEX or other command, which never runs on its own.

Edit the structure

Columns, indexes, foreign keys and the DDL of every table. Edit columns in place and NavQL applies the change as ALTER TABLE, after showing you the statement.

Database diagram

One click draws every table and the foreign keys between them, laid out automatically. Click a table to highlight what it touches; export the diagram as PNG or SVG.

Also included

The details that save time.

  • Quick SELECT TOP 100 for any table from the sidebar
  • Structure changes run in one transaction: an error leaves the table as it was
  • Settings from sys.configurations, with the defaults NavQL knows; suggested changes come as sp_configure
  • Without VIEW SERVER STATE, the Activity tab tells you what is missing
  • Visual query builder with foreign-key joins and aggregates
  • SQL editor with autocomplete, several result tabs, saved queries and history
  • SSH tunnel and SSL; read-only connections accept only reading statements

Not yet

What NavQL does not do on SQL Server today.

So you know before you download.

  • Backups (use your usual SQL Server tools for now)
  • Cancelling a single query from the Activity tab: on SQL Server you end the session

Questions

Good to know.

Can I use SQL Server on a Mac with NavQL?

Yes. NavQL runs natively on macOS (Apple Silicon) and connects to SQL Server over the network, so you do not need Windows or a virtual machine to browse and query it.

Does NavQL back up SQL Server?

Not yet. Backups cover PostgreSQL, MySQL, MariaDB, MongoDB and SQLite.

Is NavQL a replacement for SQL Server Management Studio?

For browsing, editing, queries and monitoring, often yes, and it runs on macOS and Linux too. SSMS still has far more administration features, such as Agent jobs and security management.
