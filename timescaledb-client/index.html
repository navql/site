What NavQL does with TimescaleDB

Built for the way you work with TimescaleDB.

Everything below works on TimescaleDB today. TimescaleDB speaks the PostgreSQL protocol, so it uses NavQL's PostgreSQL support, with the differences handled for you.

Detected in the status bar

NavQL shows both versions, such as PostgreSQL 16 · TimescaleDB 2.31, so you know what you are connected to.

Clean autocomplete

Internal schemas (_timescaledb_*) stay out of autocomplete; your hypertables and views are what you see.

SQL editor that knows your schema

Autocomplete for tables and columns, ⌘↵ runs the statement under the cursor, ⌘I formats, and several result sets open in tabs. Saved queries and history are kept per connection.

Activity: sessions, top queries, health

Every session on the TimescaleDB server with its query, state and wait, including who blocks whom. Cancel a query or end a session (pg_cancel_backend, pg_terminate_backend). Top queries come from pg_stat_statements.

Backups with pg_dump

Back up a whole database in one click with pg_dump --format=custom. It runs in the background, streams straight to a file, works through the SSH tunnel and shows progress. Restore with pg_restore.

Visual query builder

Pick a table, add the tables linked to it by foreign keys (or join any table with your own ON), filters, aggregates, HAVING and calculated columns. The SQL is written live, and you can save the builder or open the SQL in an editor tab.

Also included

The details that save time.

  • Grid editing with pending changes and a transactional commit
  • Related rows and foreign-key navigation
  • Health checks and Settings from pg_settings
  • Read-only connections with a READ ONLY transaction
  • Export to CSV, JSON or SQL

Not yet

What NavQL does not do on TimescaleDB today.

So you know before you download.

  • TimescaleDB-specific screens such as hypertable chunks or compression policies: query them in the editor

Questions

Good to know.

Does NavQL work with Timescale Cloud?

Yes. It is PostgreSQL with the TimescaleDB extension; paste the connection string and NavQL connects with SSL.

Can I back up a TimescaleDB database?

Yes, with pg_dump. Follow Timescale's own guidance for restoring, which needs the extension installed first.
